# Ghulam Meer Jilani — Portfolio (Vue 3 + Vite)

## Install
```bash
npm install
```

## Run
```bash
npm run dev
```

## Build
```bash
npm run build
```

## Features
- 4 themes via floating gear switcher (right side), persisted in localStorage
- Platform + Category dropdowns with Load More (6 default)
- CV download button in About section (/MEER-CV-2026.pdf)
- Reviews carousel, mobile drawer, responsive
